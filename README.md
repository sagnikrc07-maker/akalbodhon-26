## 🌟 Highlights & Features

- **🔐 Supabase Devotee Authentication & Profiles**: Email/Mobile + alphanumeric password login and Google OAuth integration with custom Puja-themed avatar customizer (🪔, 🌺, 🔱, 🪘, 🪷, 👑).
- **📅 Date-Wise Master Puja Plans & Custom Itinerary Builder**: Pre-curated schedules for Mahalaya, Shasthi, Saptami, Ashtami, Navami, and Dashami with route navigation, food stops, and rituals.
- **👥 Collaborative Plan Sharing & Member Stack**: Share itineraries directly via WhatsApp and direct links with protected login gates and live member avatar rings.
- **⏱️ Sacred Device Timers & Audio Synthesizer**: Countdown timers and ritual alerts with traditional temple chime/Dhak sounds.
- **⏳ Countdown to Akalbodhon**: Dynamic real-time ticker calculating exact days, hours, minutes, and seconds to 16th October 2026, 6:30 PM IST.
- **🥁 Web Audio Ceremonial Dhak Resonator**: Synthesized rhythmic Dhak drum tempo engine that runs natively in the browser with soundwave ripple micro-animations.
- **🗺️ Pandal Explorer & Transit Guide**: Interactive directory of iconic Kolkata pujas (Bagbazar, Maddox Square, Sreebhumi, Ekdalia, College Square, Sovabazar Rajbari) with crowd-density badges, metro walking directions, and Google Maps integration.
- **🚶‍♂️ Curated Walking & Transit Trails**: Optimized multi-pandal circuits (North Kolkata Heritage Walk, South Grandeur Circuit, Salt Lake / VIP Road Spectacle) with culinary pit-stops.
- **📻 Puja Radio Sanctuary**: Atmospheric audio player featuring Birendra Krishna Bhadra's *Mahishasuramardini*, live frequency equalizer visualizers, and an interactive 5-instrument soundboard (Dhak, Shankha, Mandir Ghanta, Kanshi).
- **🥘 Trails of Joy (Food & Shopping)**: Curated guide to iconic Kolkata street foods, Biryani joints, sweet shops, Bhog timetables, and traditional saree/craft markets (Gariahat, Hatibagan, New Market).
- **📿 Sacred Rituals Timeline**: Auspicious timings and canonical rituals for Mahalaya, Shasthi, Saptami, Sandhi Puja, Kumari Puja, and Sindoor Khela.
- **📌 Personal Itinerary & JSON Export**: Save and organize favorite pandals and food spots with local storage persistence and 1-click JSON backup export.
- **🌓 Radiant Day & High-Contrast Night Themes**: Enhanced dark mode with luminous text, amber highlights, and crystal-clear contrast.

## 🚀 1-Click Deployment to Vercel

### Option A: Using Vercel CLI (Instant)

1. Open your terminal in this repository:
   ```bash
   npx vercel
   ```
2. Accept default settings and follow the prompt.
3. Deploy to production:
   ```bash
   npx vercel --prod
   ```

### Option B: Deploy with GitHub & Vercel Web Dashboard

1. Initialize Git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial release of Akalbodhon"
   ```
2. Push to your GitHub repository:
   ```bash
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
   git push -u origin main
   ```
3. Visit [vercel.com/new](https://vercel.com/new), select **Import**, and click **Deploy**.
